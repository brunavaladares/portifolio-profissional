# Bruna Fernandes · QA Engineer

Portfólio pessoal. Site estático (HTML, CSS e JavaScript puro), sem build.

## Destaques

- Hero com um terminal que simula uma execução do Playwright, com o currículo escrito como testes
- Tema claro/escuro (respeita a preferência do sistema)
- Timeline de experiência no formato de suíte de testes
- Stack com filtro por categoria
- Responsivo e com suporte a `prefers-reduced-motion`

## Rodar localmente

Abra o `index.html` no navegador, ou:

```bash
npx serve .
```

## Publicar no GitHub Pages

Settings → Pages → Source: *Deploy from a branch* → escolha a branch e a pasta `/ (root)`.
